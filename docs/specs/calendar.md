# 캘린더 스펙

- 상태: draft · 관련 ADR: - · 리서치 참조: reference-app-research.md §2.2(캘린더 화면), §9 기회 1

## 1. 목표

날짜 스트립(date-strip.md)의 주/월 보기는 **선택 날짜 하나**를 중심으로 움직인다. 캘린더는 그 위에서 **여러 달을 오가며 훑고**, 미리 정해 둔 날짜까지 얼마나 남았는지(D-day)를 항상 보이는 자리에 둔다. 새 화면을 만들지 않고 **인사이트 패널의 슬롯 하나**(timer.md와 같은 자리)로 더한다.

## 2. 화면과 인터랙션

```
 인사이트 패널 슬롯(280px):
 ┌ 캘린더 ─────────────────────┐
 │ ‹  2026년 9월 ▾  ›  [올해▾] │   ← ▾: 연도 선택 팝오버
 │ 월 화 수 목 금 토 일         │
 │ … (date-strip DateCell 재사용, 40×40) …
 │ ── D-day ──                  │
 │ 🎂 생일        D-12          │   ← 임박순, 지난 건 "D+3" 접힌 목록
 │ 📌 발표        D-1           │
 │ [+ D-day 추가]                │
 └───────────────────────────────┘
```

- 셀 클릭: 날짜 스트립의 선택 날짜를 그 날로 옮기고(메인이 그 날로 스크롤), 스트립 보기(주/월)는 그대로 둔다.
- `‹`/`›`: ±1달. `[올해▾]`: 연도 선택 → 그 해 1월로.
- D-day 항목 클릭: 그 날짜로 선택 이동. `[+ D-day 추가]`: 인라인 폼(제목 1줄 + 날짜 입력).
- 좁은 화면: 패널이 오버레이로 열릴 때 이 슬롯도 포함(app-shell §2-B와 동일 규약).

### 상태

- **빈 상태(D-day 없음)**: "다가오는 날을 기록해 보세요" + `[+ D-day 추가]`만.
- **로딩**: 달력 그리드는 date-strip과 같은 규약(요약만 지연). D-day 목록은 즉시.
- **에러**: D-day 저장 실패 시 폼 유지 + `role=alert`.

## 3. 규칙

- R1. 그리드는 date-strip `DateCell`을 그대로 재사용한다(오늘 링·선택 채움·카테고리 점·✓ 배지). 새 시각 언어를 만들지 않는다.
- R2. 셀 선택은 **메인 앱의 선택 날짜**(date-strip과 같은 스토어)를 바꾼다. 패널의 달 표시는 독립적으로 넘길 수 있다(패널은 6월을 보여도 선택 날짜는 9월일 수 있다).
- R3. D-day는 제목 1~30자 + 날짜(과거·미래 모두 허용). 최대 50개.
- R4. 정렬: 오늘 포함 미래(`date >= 오늘`)는 D-day 오름차순(가까운 순), 지난 항목은 접힌 "지난 날" 섹션에 최근순.
- R5. 표기: 오늘이면 `D-day`, 미래면 `D-n`, 과거면 `D+n`.
- R6. D-day는 카테고리·투두와 연결되지 않는 독립 이벤트다(할 일 자동 생성 없음). 반복 없음(routine.md와 다른 축).
- R7. D-day 삭제는 확인 없이 즉시 + 6초 되돌리기 토스트(todo.md 삭제 확인 패턴과 동일한 소프트 삭제).
- R8. 연도 선택 팝오버는 현재 연도 기준 ±10년.

## 4. 데이터

- domain 신규 `Dday = Meta & { title, date: DateKey }`. D-n 계산은 `today`를 주입받는 순수 함수(timer.md R3와 같은 이유).
- 레포지토리 `DdayRepository.list()`·`upsert(Persistable<Dday>)`. 그리드 요약은 date-strip의 `TodoRepository.listByDateRange`를 그대로 쓴다(별도 조회 없음).

## 5. 접근성

- 그리드는 date-strip R16 규약 그대로(`role=grid`). D-day 목록은 `ul`, 각 행 "생일까지 12일"로 낭독.
- `[+ D-day 추가]` 폼: 제목 입력 초기 포커스, `Enter` 저장, `Esc` 취소.
- 연도 팝오버는 `listbox` + 방향키 이동.

## 6. 범위 밖

- 공휴일·음력, 다른 사람과 공유되는 일정, D-day 반복(생일 매년 — routine.md 확장 후보), 캘린더 위에 일정 겹쳐 보기(막대형 간트), 여러 달을 한 화면에 나란히 늘어놓는 레이아웃(스크롤로 대체).

## 7. 완료 조건

- [ ] R1~R8 테스트, D-n 계산 경계(오늘=D-day, 어제=D+1) 단위 테스트.
- [ ] 셀 클릭 → 메인 날짜 스트립 갱신 통합 테스트 1개.
- [ ] 키보드만으로 D-day 추가·삭제·되돌리기.
- [ ] 라이트/다크 스크린샷(D-day 0개/여러 개, 연도 팝오버).
