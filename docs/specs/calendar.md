# 캘린더 스펙

- 상태: implemented · 관련 ADR: -

## 1. 현재 범위

월·주 보기, 년·월 선택, 날짜 이동은 [date-strip.md](date-strip.md)와 [calendar-layout.md](calendar-layout.md)가 정의한다. 이 문서는 별도 달력 이벤트 기능을 추가하지 않는다.

## 2. D-day 종료

2026-09-30 사용자 피드백에 따라 D-day 화면, 추가·수정·삭제 진입점을 앱에서 제거한다. 사이드바와 인사이트에 D-day 섹션을 표시하지 않는다. 기존 기기에 저장된 D-day 행은 삭제하거나 다른 데이터로 바꾸지 않고 보존하며 화면에서 무시한다. 백업·동기화 호환성을 위한 기존 데이터 계층은 별도 마이그레이션 결정 전까지 유지한다.

## 3. 검증

- 사이드바 고정 컬럼과 드로어 모두 D-day 진입점이 없다.
- 과거 D-day 행이 남아 있어도 달력·사이드바와 다른 저장 데이터가 정상 표시된다.
