# 통계 스펙

- 상태: draft · 관련 ADR: - · 리서치 참조: reference-app-research.md §2.7(통계/리포트), §3-5, §4(프리미엄 번들)

## 1. 목표

레퍼런스 앱은 통계를 유료 번들에 묶지만, Tasky는 계정도 결제도 없으므로(P5) **전부 무료로** 보여준다. completion-rate.md의 "오늘" 한 장을 기간(주/월/올해)으로 넓히고, 타이머 세션(timer.md)을 모아 집중 시간을 더한다. 새 숫자를 만들지 않는다 — 이미 있는 도메인 함수를 기간에 대해 반복 적용할 뿐이다.

## 2. 화면과 인터랙션

통계 화면(커맨드 팔레트 "통계 보기" 또는 사이드바 하단 진입점, 메인 컬럼 전체 대체):

```
 [지난 7일 ▾] [지난 30일] [올해] [기간 지정]     ← 탭형 토글, 기본 "지난 7일"

 ┌ 달성률 추이 ──────────────┐  ┌ 카테고리 비율 ────────┐
 │ ▁▃▅█▂▇▅  (막대, 요일 라벨) │  │ 📝 todo   ■■■□ 42%    │
 └────────────────────────────┘  │ 📚 공부   ■■□□ 31%    │
 ┌ 연속 달성 ─────────────────┐  └────────────────────────┘
 │ 🔥 5일째 100%               │  ┌ 집중 시간 ────────────┐
 └────────────────────────────┘  │ 총 3시간 20분          │
 ┌ 활동 히트맵(최근 12주) ────────────────────┐│ 📝 장보기  42분        │
 │ 월▢▢▨▧▪ 화▢▪▨…(7×12, 진하기=달성률)      │└────────────────────────┘
 └──────────────────────────────────────────┘
```

### 상태

- **빈 상태(선택 기간에 투두 없음)**: 각 카드가 "이 기간에 기록이 없어요"로 대체.
- **로딩**: 카드별 스켈레톤(기존 앱 스켈레톤 톤 재사용).
- **에러**: 카드 단위 "불러오지 못했어요 [다시 시도]"(카드 하나 실패가 나머지를 막지 않는다).

## 3. 규칙

- R1. 기간 프리셋: 지난 7일(오늘 포함)·지난 30일·올해(1/1~오늘)·기간 지정(`input[type=date]` 2개, 최대 366일).
- R2. 추이 막대: 하루 단위 `completionRate`(completion-rate.md §4 재사용) 배열. 투두 0개인 날은 빈 칸(0%가 아님 — completion-rate R1과 같은 구분).
- R3. 카테고리 비율: 기간 내 완료된 투두 수를 카테고리별로 합산한 비율(`summarizeByCategory`를 기간 누적으로 확장한 순수 함수). 삭제된 카테고리는 "(삭제됨)" 묶음.
- R4. **연속 달성(스트릭)**: 선택 날짜(기본 오늘)에서 과거로, `completionRate === 1`(투두 ≥ 1)인 날이 끊기지 않고 이어진 일수. 투두 0개인 날은 스트릭을 끊지 않고 건너뛴다(기록할 게 없던 날은 실패가 아니다).
- R5. 집중 시간: 기간 내 `FocusSession`(status ∈ completed·canceled) `elapsedSeconds` 합계. 투두별 상위 5개 + 나머지 "기타"로 합산.
- R6. 히트맵: 최근 12주 × 7일, 칸 진하기 4단계(0% / 1~~49% / 50~~99% / 100%, 투두 0개는 5번째 톤 "기록 없음"). 오늘 이후 칸은 렌더하지 않는다.
- R7. 모든 계산은 저장소에서 기간 전체를 **한 번**(`listByDateRange` 확장 또는 신규 `listByDateRangeAll`)에 읽어 메모리에서 합산한다 — 날짜마다 개별 조회하지 않는다(date-strip R17과 같은 원칙).
- R8. 새 차트 라이브러리를 추가하지 않는다(CLAUDE.md §7-9, 사용자 확인 없는 의존성 추가 금지) — 막대·히트맵은 SVG/CSS로 직접 그린다.

## 4. 데이터

- domain: 완료율·카테고리 비율은 completion-rate.md의 함수를 기간 배열에 매핑하는 순수 함수(`summarizeRange(days, todos, categories)`), 스트릭은 `computeStreak(dailyRates, from)`, 집중 시간 합계는 `summarizeFocusSeconds(sessions, by: 'day'|'todo'|'category')`. 타입 변경 없음(기존 `Todo`·`FocusSession`·`Category` 조합).
- 레포지토리: 기존 `TodoRepository.listByDateRange`·`FocusSessionRepository.listAll`(range 필터 인자 추가 검토) 재사용. 신규 저장 엔티티 없음 — 통계는 항상 **재구성**이다(timer.md §4 각주와 동일 원칙).

## 5. 접근성

- 막대·히트맵은 `role=img` + 요약 `aria-label`("최근 7일 평균 달성률 68%"), 칸 단위 상세는 시각적으로 숨긴 대체 `table`을 함께 제공(스크린리더 전용).
- 기간 토글은 `radiogroup`. 카드 에러의 `[다시 시도]`는 포커스를 잃지 않는다.

## 6. 범위 밖

- 엑셀·CSV 내보내기(product-overview.md §7 비목표), 다른 사용자와 비교, AI 인사이트/추천, 프리미엄 구분(Tasky는 전부 무료), 검색 전용 화면(팔레트로 대체).
