# 키보드 단축키 & 커맨드 팔레트 스펙

- 상태: approved · 관련 ADR: - · 리서치 참조: reference-app-research.md §2.8(검색이 프리미엄), §9 기회 3·4, 과제 6

## 1. 목표

데스크탑에서만 가능한 것을 Tasky의 차별점으로 만든다: 손을 키보드에서 떼지 않고 하루를 정리하고, 레퍼런스 앱에서 유료였던 검색을 `Mod+K` 팔레트로 무료·즉시 제공한다.

**MVP 포함 판단**: §3-A 단축키는 MVP 필수(접근성 요구 P6와 구현이 겹쳐 추가 비용이 작다). §3-B 팔레트는 MVP에 포함하되 **컷 라인**이다 — 다른 스펙이 늦어지면 1.5로 미룬다. 근거: (1) 검색 전용 화면 없이 검색을 제공하는 가장 싼 방법, (2) 명령 레지스트리가 Phase 2 기능(캘린더·통계)의 진입점이 되어 메뉴를 늘리지 않게 해 준다(P2), (3) 단축키 인프라 위에 얹으면 M 크기.

## 2. 화면과 인터랙션

```
 Mod+K 팔레트(모달, 560px, 화면 상단에서 15vh):        `?` 도움말(다이얼로그):
 ┌────────────────────────────────────────────┐        ┌ 단축키 ──────────────────┐
 │ 🔍 [ 할 일 검색 또는 명령…                 ] │        │ 이동   ←/→  하루   Shift+←/→ 한 주 │
 │ 명령                                        │        │        T    오늘   Mod+K  팔레트  │
 │ ▸ + 새 할 일 (todo)                    N     │        │ 할 일  N    추가   Space  완료    │
 │   ↷ 오늘로 이동                        T     │        │        Enter 편집  Delete 삭제    │
 │   ☾ 다크 모드로 전환                         │        │        Alt+↑/↓ 순서              │
 │   ⇅ 백업 내보내기                            │        │ 화면   Mod+\  사이드바  ?  도움말 │
 │ 할 일 (3)                                   │        └──────────────────────────┘
 │   ○ 장보기            📝 todo · 9월 17일     │
 │   ◉ 장보기 목록 정리   📝 todo · 9월 3일      │
 └────────────────────────────────────────────┘
```
- 입력이 비어 있으면 명령만(최근 실행 순). 입력하면 명령(이름·키워드 접두/부분 일치) + 투두(제목 부분 일치) 두 섹션.
- `↑/↓` 이동, `Enter` 실행, `Esc` 닫기. 투두 선택 → 그 날짜로 이동 + 그 항목 포커스(하이라이트 400ms).
- 좁은 화면: 팔레트 전폭·상단 고정. 단축키는 물리 키보드 있을 때만 의미 있음(문서화만).
- 상태: **빈 결과** "결과가 없어요 — Enter로 '장보기'를 오늘 할 일로 추가"(첫 카테고리에 추가, 카테고리 0개면 이 줄 없음). **로딩** 검색 80ms 디바운스, 스피너 없음. **에러** 검색 실패 시 투두 섹션 숨김 + 명령만.

## 3. 규칙

### 3-A. 단축키
- R1. 전역 단축키(포커스가 입력·textarea·contenteditable·열린 메뉴/다이얼로그에 없을 때만): `←`/`→` ±1일, `Shift+←/→` ±7일, `T` 오늘, `N` 첫(또는 마지막 사용) **활성** 카테고리 입력 행 열기, `?` 도움말, `Mod+\` 사이드바 접기/펼치기, `Mod+K` 팔레트(입력 중에도 동작).
- R2. 항목 포커스 상태 키(todo.md §5): `Space` 완료, `Enter` 편집, `Delete`/`Backspace` 삭제, `Alt+↑/↓` 순서. 카테고리 행: `Alt+↑/↓` 순서.
- R3. `Mod` = macOS `⌘`, 그 외 `Ctrl`. 도움말·팔레트 표기는 플랫폼에 맞춰 `⌘K` / `Ctrl+K`.
- R4. 단축키는 브라우저·OS 기본 동작과 충돌하지 않는다(`Mod+K`는 `preventDefault`, 나머지 단일 키는 수식키 없이). `Alt+←/→`(뒤로/앞으로)는 쓰지 않는다.
- R5. 도움말은 등록된 단축키 목록에서 생성된다(수동 표 금지). 새 단축키는 등록만 하면 도움말에 나타난다.
- R6. 한글 입력 상태(IME)에서 `N`·`T` 등 단일 키가 눌려도 조합 중(`isComposing`)이면 무시한다.

### 3-B. 커맨드 팔레트
- R7. 명령은 각 기능이 레지스트리에 `{ id, label, keywords, shortcut?, run, when? }`로 등록한다. MVP 명령: 새 할 일(활성 카테고리별), 오늘로 이동, 날짜로 이동(`YYYY-MM-DD` 또는 `9/18` 입력 인식), 이전/다음 주, 테마 전환(라이트/다크/시스템), 새 카테고리, 백업 내보내기, 백업/복원 열기, 단축키 도움말, 사이드바/인사이트 접기, 타이머 시작(할 일 선택)·일시정지/재개·중지(timer.md).
- R8. 명령 검색: 공백 제거·소문자화 후 `label`·`keywords`에 부분 일치. 한글 초성 검색은 하지 않는다(1.5 검토).
- R9. 투두 검색: 삭제되지 않은 투두의 제목 부분 일치(대소문자 무시), 최대 20개, 날짜 내림차순 → 미완료 우선. 메모는 검색하지 않는다.
- R10. 검색 응답: 10,000개 투두에서 입력 후 150ms 안에 결과 표시(80ms 디바운스 포함).
- R11. 열릴 때 입력에 포커스, 닫히면 열기 전 포커스로 복귀. 실행 후 팔레트는 닫힌다(연속 명령 없음).
- R12. 최근 실행 명령 5개를 기기별로 기억한다(localStorage `tasky.palette.v1`).

## 4. 데이터

- domain: 날짜 문자열 파서(`YYYY-MM-DD`, `M/D`, `M월 D일`)와 명령 매칭 함수는 순수 함수. 타입 변경 없음.
- 레포지토리: `TodoRepository.search(query, limit)`(R9 정렬 포함). 인덱스 없이 전체 스캔 허용(TECH_PLAN §8).

## 5. 접근성

- 팔레트: `role="dialog" aria-modal aria-label="명령 팔레트"`, 입력 `role="combobox" aria-expanded aria-controls aria-activedescendant`, 목록 `role="listbox"`, 항목 `role="option"`. 섹션 제목은 `role="group" aria-label`.
- 결과 수는 `aria-live="polite"`로 "결과 5개".
- 도움말 다이얼로그는 표(`table`)로, 키는 `<kbd>`.
- 단일 키 단축키는 항상 대체 경로(버튼·메뉴)가 있다. 단축키 끄기 설정은 없음(1.5 검토, WCAG 2.1.4는 단일 키 단축키에 끄기/재설정을 권장 — R1의 포커스 조건이 완화 근거이며 위험으로 기록).

## 6. 범위 밖

- 단축키 사용자 정의, 초성 검색, 메모 검색, 자연어 날짜("다음주 월요일"), 다중 선택 명령, 팔레트에서 카테고리·투두 수정.

## 7. 완료 조건

- [ ] R1~R6 테스트(입력 중 무시, IME 무시, Mod 매핑). 도움말이 레지스트리에서 생성됨(R5).
- [ ] R7~R12 테스트(명령 매칭, 날짜 파서, 검색 정렬·상한, 성능 10,000개 150ms).
- [ ] 카테고리 생성 → 투두 추가 → 완료 → 날짜 이동을 키보드만으로 완주하는 E2E 1개(product-overview P6).
- [ ] 팔레트 라이트/다크 스크린샷.
