# Tasky 제품 개요

- 상태: approved · 관련 ADR: ADR-0001~0004 · 리서치 참조: reference-app-research.md §1, §6, §8, §9

## 1. 한 줄 정의

Tasky는 **하루를 카테고리 색으로 꾸미며 할 일을 체크하는, 계정 없는 로컬 우선 데스크탑 웹앱**이다.
레퍼런스 앱의 "예쁘게 기록하는 투두" 감성을 데스크탑(넓은 화면·키보드)에 맞게 옮기되, 기능을 쌓지 않고 **핵심 루프(날짜 → 카테고리 → 투두 → 체크 → 달성률)** 를 가장 빠르고 기분 좋게 만든다.

## 2. 타깃

| 우선순위 | 사용자 | 환경 | 보장 수준 |
|---------|--------|------|----------|
| 1 | 하루 계획을 색으로 정리하고 싶은 개인(20~30대, 다이어리 꾸미기 감성 선호) | 데스크탑 브라우저 1280×800 이상, 최신 Chromium/Firefox/Safari | 모든 스펙 완전 지원 |
| 2 | 같은 사용자의 노트북 좁은 창·태블릿 | 1024~1279px | 레이아웃 붕괴 규칙(app-shell R7) 적용, 기능 동일 |
| 3 | 폰 브라우저 | 400~767px | 깨지지 않음·핵심 루프 가능. 최적화는 비목표 |

## 3. 핵심 가치 (우선순위 순)

1. **즉시성** — 첫 화면 로드 후 1초 안에 투두를 입력할 수 있다(로그인·온보딩 없음).
2. **감성** — 파스텔 카테고리 색, 큰 라운드, 넉넉한 여백, 체크 마이크로 애니메이션(수치는 `theme.md`).
3. **내 데이터** — 모든 데이터는 브라우저 안(IndexedDB). 한 번의 클릭으로 JSON 백업/복원.
4. **데스크탑다움** — 3컬럼 레이아웃, 키보드만으로 완주, 커맨드 팔레트.

## 4. 설계 원칙 (레퍼런스 앱의 약점에서 도출, 각 원칙은 검증 기준을 가짐)

| # | 원칙 | 근거(리서치) | 검증 기준 |
|---|------|------------|----------|
| P1 | **헤더는 얇게** | §2.1 "헤더가 화면의 2/5를 차지해 답답하다" | 메인 컬럼 상단 고정 영역(월 표시+날짜 스트립+달성률) 높이 ≤ 160px |
| P2 | **기능은 더하지 않고 접는다** | §9 과제 3 "업데이트마다 기능이 늘어 답답" | 메인 컬럼에는 날짜·달성률·투두만. 그 외 정보는 접을 수 있고 상태가 기억되는 패널로만 추가 |
| P3 | **클릭 1회 규칙** | §2.1 FAB·바텀시트(2단계) | 투두 추가·완료·날짜 이동은 홈 화면에서 클릭 1회 또는 키 1회로 시작 |
| P4 | **색은 카테고리에서만** | §3-1 투두별 색 개별 지정(선택 과다) | 사용자가 고르는 색은 카테고리 색과 강조색 2곳뿐. 투두 개별 색 없음 |
| P5 | **무계정·로컬 우선** | §4 백업/동기화가 로그인 기반 | 계정·서버 없이 모든 기능 동작. 백업은 파일로 |
| P6 | **키보드 완주** | §9 기회 3·과제 6 | 카테고리 생성 → 투두 추가 → 체크 → 날짜 이동을 마우스 없이 수행(shortcuts.md) |
| P7 | **부재 기능은 Phase 2, 모델은 막지 않기** | 브리프에서 지적된 D-day 부재, §2.4 루틴 | MVP 데이터 모델은 `TECH_PLAN.md §12` 체크리스트를 만족 |

## 5. MVP(Phase 1) 범위 → 스펙 매핑

| 기능 | 스펙 | 포함 근거 |
|------|------|----------|
| 3컬럼 앱 셸, 반응형, 빈/로딩/에러 상태 | `app-shell.md` | 모든 기능의 그릇 |
| 주 단위 날짜 스트립, 오늘, 날짜 점프 | `date-strip.md` | 핵심 루프 1단계 |
| 카테고리 CRUD·색·이모지·정렬·종료(완료/중단)·삭제 시 완료 기록 보존 | `category.md` | 감성의 원천(색), 기록 보존 |
| 투두 CRUD·완료(하단 이동)·메모·날짜 이동·순서·삭제 확인 | `todo.md` | 핵심 루프 |
| 달성률 링·카테고리별 요약·100% 보상 | `completion-rate.md` | 보상감 |
| 라이트/다크, 강조색, 팔레트, 토큰 | `theme.md` | GUI 유사도의 핵심 |
| JSON 백업/복원 | `backup.md` | 로컬 우선이면 데이터 유실 대책은 필수 |
| 단축키 + 커맨드 팔레트 | `shortcuts.md` | 데스크탑 차별점(팔레트는 컷 라인, §6) |
| 설치·오프라인·업데이트·저장소 지속 | `pwa.md` | "앱처럼" 느끼는 최소 조건 |
| 포커스 타이머(카운트다운·투두 연결·세션 기록) | `timer.md` | 사용자 지시로 MVP 포함. 컷 라인 아님 |

## 7. 비목표 (MVP에서 만들지 않는다)

- 계정, 로그인, 서버, 실시간 동기화, 푸시 알림·알림 API(타이머 종료도 소리·화면만), 리마인더 시간.
- 투두 개별 색, 스티커·캐릭터·마스코트(레퍼런스 앱 자산을 연상시키는 일러스트 포함), AI 추천·자동 일기.
- 뽀모도로 자동 사이클·스톱워치(타이머는 카운트다운만), 검색 전용 화면(팔레트 검색으로 대체), 엑셀 내보내기, 다국어(한국어만).
- 모바일 제스처(스와이프·롱프레스) 재현. 대체는 hover 액션·컨텍스트 메뉴·단축키.
- 날짜 없는 투두(보관함), 반복, 하위 투두, 태그, 첨부.
