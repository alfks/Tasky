# 날짜 스트립 스펙

- 상태: implemented · 관련 ADR: - · 리서치 참조: reference-app-research.md §2.1(헤더·날짜 이동), §2.2(캘린더 점 표시), §9 기회 3

## 1. 목표

레퍼런스 앱에서 좌우 스와이프로 하루씩 옮기던 것을, 데스크탑에서는 **한 주가 한눈에 보이는 스트립**으로 바꾼다. 어느 날에 무엇이 얼마나 있었는지 카테고리 색 점으로 보이고, 오늘로 돌아오는 데 클릭 1회면 된다.

## 2. 화면과 인터랙션

### 2-A. 데스크탑

```
 ‹   2026년 9월 ▾                                   [오늘]   ›
 ┌──────┬──────┬──────┬────────┬──────┬──────┬──────┐
 │  월  │  화  │  수  │   목   │  금  │  토  │  일  │   ← 요일: 토 파랑, 일 빨강(토큰)
 │  14  │  15  │  16  │ [ 17 ] │  18  │  19  │  20  │   ← 오늘: 강조색 테두리 링, 선택: 강조색 채움
 │ ●●   │ ●    │      │ ●●● ✓  │ ●    │      │      │   ← 카테고리 색 점 최대 3개, 100%면 ✓ 배지
 └──────┴──────┴──────┴────────┴──────┴──────┴──────┘
   셀 --cal-cell-w × --cal-cell-h-week, 간격 --cal-gap, 라운드 --radius-lg(값·좁은 화면 갈래의 단일 소스는 calendar-layout.md §2)
```

- `‹` `›`: 7일 이동(요일 유지). `[오늘]`: 오늘 선택 + 그 주로 이동. 오늘이 이미 선택돼 있으면 비활성.
- `2026년 9월 ▾`: 클릭 시 **년·월 피커**(연도 스테퍼 + 월 3×4 격자, 규칙·상호작용의 단일 소스는 calendar-layout.md §3)가 열린다. 월을 확정하면 선택 날짜의 **일(日)은 유지한 채** 그 년·월로 이동한다.
- 셀 클릭: 그 날 선택. 셀 hover: 배경 `--color-surface-2`.
- 미완료 투두 항목을 셀 위로 드래그해 놓으면 그 날짜로 이동(todo.md R10). 드롭 가능 셀은 강조색 점선 테두리.

### 2-A-2. 월 보기 (데스크탑·좁은 화면 공통)

```
 ‹   2026년 9월 ▾                      [월 보기]  [오늘]   ›     ← ‹ › 는 ±1달
 ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┐
 │  월  │  화  │  수  │  목  │  금  │  토  │  일  │   ← columnheader 줄에서 한 번만
 ├──────┼──────┼──────┼──────┼──────┼──────┼──────┤
 │  31  │   1  │   2  │   3  │   4  │   5  │   6  │   ← 31 은 지난 달(숫자만 --color-muted)
 │  ●   │      │  ●●  │      │      │      │      │
 │  …   …   (4~6줄, 그 달의 모양에 따라)
 └──────┴──────┴──────┴──────┴──────┴──────┴──────┘
   셀 --cal-cell-w × --cal-cell-h-month(요일 줄이 빠진 만큼 낮다), 간격·라운드는 주 보기와 같다(calendar-layout.md §2)
```

- 전환 버튼 하나로 주 ↔ 월을 오간다. 글자는 **가려는 곳**을 가리킨다(주 보기에서는 "월 보기").
- 보기를 바꿔도 **선택 날짜는 바뀌지 않는다**. 월 보기가 보여 주는 달은 선택(또는 포커스) 날짜의 달이다.

### 2-B. 1열 (달력 컬럼과 선택 날짜 패널이 나란히 서지 않는 폭 — 경계는 calendar-layout.md §1-C)

```
 ‹  9월 ▾        [오늘]  ›
 ← 월 14 · 화 15 · 수 16 · [목 17] · 금 18 · 토 19 · 일 20 →   (가로 스크롤, 스냅, 선택 셀 중앙)
```

- 스트립은 **모든 폭에서 가운데**다(`justify-content: safe center`) — 1열에서 왼쪽에 붙어 달력만 치우쳐 보이던 것을 고쳤다. 폭이 모자라 넘치면 자동으로 시작 정렬이 돼 왼쪽 칸이 잘리지 않는다(calendar-layout.md R9·R11 이 360 에서도 격자가 들어감을 보장하므로 실제로 넘치는 폭은 없다).

### 2-C. 상태

- **로딩**: 요약(점·✓)만 지연 표시. 셀·숫자는 즉시. 스켈레톤 없음.
- **빈 상태**: 투두가 없는 날은 점 없음. 별도 문구 없음.
- **에러**: 요약 조회 실패 시 점을 숨기고 앱 셸 토스트(app-shell §2-C).

## 3. 규칙

- R1. 스트립은 선택 날짜가 속한 **월요일 시작 7일**을 보여준다.
- R2. 앱 시작 시 선택 날짜는 항상 **오늘**(기기 로컬 시간대). 마지막 선택 날짜를 복원하지 않는다.
- R3. 오늘 셀은 강조색 2px 링, 선택 셀은 강조색 채움 + `--color-on-accent` 글자. 오늘이면서 선택이면 채움만.
- R4. `‹`/`›`는 ±7일. 전역 단축키 `←`/`→`는 ±1일, `Shift+←/→`는 ±7일(shortcuts.md).
- R5. `[오늘]`은 선택 날짜 = 오늘일 때 `disabled`.
- R6. 이동 가능 범위는 `1970-01-01` ~ `2099-12-31`. 범위 밖으로 가는 버튼은 비활성.
- R7. 점: 그날 삭제되지 않은 투두가 1개 이상인 카테고리(종료·삭제된 카테고리 포함, 활성 `order` 순 → 종료 → 삭제됨)의 색을 최대 3개. 4개 이상이면 3개 + "+n" 텍스트(`--text-xs`).
  삭제된 카테고리의 색은 `CategoryRepository.listDeletedByIds` 로 읽는다(ADR-0014) — 중립색으로 뭉개지 않는다. 색을 모르는 점(대비 1.97:1)은 사실상 보이지 않으면서 3칸 중 하나를 먹어 보이는 카테고리를 밀어내기 때문이다. 그래도 색을 못 찾은 카테고리는 점을 만들지 않고 넘침으로도 세지 않으며, 그 개수는 셀 접근성 이름의 "할 일 N개 중 M개 완료" 에 그대로 남는다.
- R8. ✓ 배지: 그날 투두 ≥ 1 이고 전부 완료일 때만.
- R9. 요일 색: 토요일 `--color-saturday`, 일요일 `--color-sunday`, 그 외 `--color-muted`. 색은 보조 정보이며 요일 텍스트가 항상 있다.
- R10. 날짜 변경 후 100ms 안에 해당 날짜 투두 목록이 그려져야 한다(요약 점은 늦어도 됨). 애니메이션은 120ms 페이드 이하, reduced-motion에서는 없음.
  상한이 걸리는 자리는 **날짜를 바꿀 때 실제로 움직이는 셀 색 전환**이고 점 페이드도 같다. 둘 다 `--motion-xfast`(theme.md §3-D = 120ms)를 참조한다 — 수치는 토큰 한 곳에만 살고 컴포넌트에 리터럴 `ms` 를 쓰지 않는다(`--motion-fast` 150ms 는 상한을 넘으므로 이 자리에 쓸 수 없다).
- R11. 날짜 표기: 월 표시 `YYYY년 M월`, 셀 `D`(0 채움 없음), 요일 한 글자. 접근성 이름은 `9월 17일 목요일`(+ "오늘", + 요약이 있으면 "할 일 N개 중 M개 완료").
  **선택 상태는 이름에 넣지 않는다** — `role="radio" aria-checked` 가 전담한다. 이름에도 넣으면 스크린리더가 한 칸 지날 때마다 "선택됨"을 두 번 읽는다(AX 트리 실측). "오늘"은 대응하는 ARIA 상태가 없어 이름이 유일한 통로이므로 남긴다.
- R12. 자정을 넘기면(탭을 켜 둔 채) 오늘 표시가 갱신된다(1분 간격 확인). 선택 날짜는 바뀌지 않는다.
- R13. 드래그 중인 투두를 셀에 놓으면 이동 후 토스트 "9월 18일로 옮겼어요 [되돌리기]".

### 3-A. 월 보기 규칙

- R14. 보기는 **주/월** 둘이고 전환 버튼 하나로 오간다. 보기 상태는 `date-strip-store` 에 있고 **기기별로 기억한다**(localStorage `tasky.datestrip.v1`, `{ view: 'week' | 'month' }` — `lib/view-pref.ts`, 백업·동기화 대상 아님, app-shell.md R5 와 같은 부류). 앱을 열면 마지막으로 보던 보기다 — 월 보기를 골라 둔 사람이 새로고침마다 주 보기로 되돌아가던 것을 고쳤다(사용자 피드백). **선택 날짜는 여전히 저장하지 않는다(R2)** — 선택이 언제나 오늘이면 월 격자도 언제나 오늘이 든 달이라 두 상태가 어긋날 일이 없다. 저장이 없거나 값이 깨졌으면(`'week'|'month'` 가 아님, 접근이 throw) 주 보기다. 월 보기에서 `‹`/`›` 는 ±1달이고 이름도 "이전 달"/"다음 달"이 된다. 목적지 달에 없는 날(1/31 → 2월)은 그 달의 마지막 날로 자른다 — 달을 건너뛰지 않는다. 전역 단축키 `←/→`·`Shift+←/→` 의 뜻은 보기와 무관하게 그대로다(R4).
- R15. 격자는 1일이 속한 주의 **월요일**부터 말일이 속한 주의 **일요일**까지다(4~6줄, 항상 7의 배수, 끊김 없는 연속 범위). 6줄로 고정해 빈 줄을 채우지 않는다.
- R16. 격자의 칸은 주 보기와 **같은 컴포넌트**다(`DateCell`) — 오늘 링·선택 채움·잉크 링·카테고리 색 점·✓ 배지·드롭 강조가 모두 같다. 보기에 따라 갈리는 것은 셋뿐이다: (1) 노출 역할 `radio`(+`aria-checked`) ↔ `gridcell`(+`aria-selected`), (2) 요일 글자는 격자에서 맨 위 `columnheader` 줄이 한 번만 보여 준다, (3) 그만큼 칸이 낮다(토큰 `--cal-cell-h-week` → `--cal-cell-h-month`, calendar-layout.md §2). 이 달 밖 날짜는 **숫자만** `--color-muted` 로 물리고(점·✓ 는 그대로) **누르면(마우스·터치·펜·Enter/Space, 입력 종류 무관) 선택된다 — 그 날이 든 달로 격자가 넘어가고 그 칸이 선택·포커스 대상이다.** 그러려면 **칸이 포커스를 받는 것만으로는 격자가 옮겨지지 않아야 한다 — 격자를 옮기는 것은 키보드 이동(R18)과 선택뿐이다.** 포커스만으로 앵커를 옮기면 격자가 click 보다 먼저 다시 그려져 click 이 다른 칸에 떨어지고 선택이 일어나지 않는다(마우스·터치 실브라우저에서 확인된 버그 — jsdom 은 요소 참조를 유지해 잡지 못했다). 닿을 수 있는 칸은 지금 보이는 칸뿐이고 주 보기의 칸은 전부 같은 주라, 이 규칙이 실제로 작동하는 경우는 "월 보기의 이 달 밖 칸" 하나다. 투명도로 흐리면 대비가 예측 불가능해지고 할 일이 적은 날처럼 보인다.
- R17. 월 보기의 요약도 **`listByDateRange` 한 번**으로 읽는다(격자 양끝). 칸이 6배여도 조회 수는 1이다. 저장소 변경 신호(`summaryRevision`)는 주/월이 **같은 훅·같은 의존성**을 쓴다 — 보기마다 배선이 갈리면 한쪽에서만 무효화가 빠진다.
- R18. 격자 안에서 `←/→` 는 하루, `↑/↓` 는 **일주일**, `Home/End` 는 그 줄의 월·일요일이다. `↑/↓` 는 월 보기에서만 가로챈다(주 보기는 한 줄이라 갈 곳이 없다). 등록된 전역 단축키와 겹치지 않는다(`↑/↓` 단독은 카탈로그에 없고 `Alt+↑/↓` 는 투두 항목 범위다).

## 4. 데이터

- domain: `DateKey`('YYYY-MM-DD'), 주 시작(월요일) 계산, `±n일` 계산은 순수 함수. 타입 변경 없음.
- 레포지토리: `TodoRepository.listByDateRange(from, to)`(보이는 날짜 전부의 요약용 — 주 7일 또는 월 격자 28~42일, R17) · `CategoryRepository.list({ includeClosed: true })` · 그 목록에서 못 찾은 카테고리 id 만 `CategoryRepository.listDeletedByIds(ids)`(R7 의 삭제됨 색, ADR-0014 — 살아 있는 조회는 그대로 툼스톤을 감춘다). 요약(카테고리 집합·전부 완료 여부)은 도메인 순수 함수로 계산.

## 5. 접근성

- 스트립은 `role="radiogroup"` + 셀 `role="radio" aria-checked`(선택). 셀 안에서 `←/→`로 포커스 이동(roving tabindex), `Home/End`는 월/일요일, `Enter/Space`로 선택.
- 월 보기는 `role="grid"` + `role="row"` + 요일 `role="columnheader"` + 셀 `role="gridcell" aria-selected`(R16·R18). 이름("날짜 선택")은 두 보기가 같다.
- 스트립에 포커스가 있을 때의 `←/→`는 셀 이동이고, 포커스가 밖에 있을 때의 `←/→`는 전역 날짜 이동(shortcuts.md R1).
- `‹`/`›`/`[오늘]`은 `button` + `aria-label`("이전 주", "다음 주", "오늘로 이동").
- 점·✓는 `aria-hidden`, 셀 접근성 이름에 "할 일 3개 중 2개 완료"를 덧붙인다.
- 드롭 존은 키보드 대안(todo.md R10 메뉴의 날짜 이동)이 있으므로 드래그만으로 되는 기능이 없다.

## 6. 범위 밖

- 주 시작 요일 설정, 2주 표시, 음력·공휴일.
- 월간 **보기**는 여기 §2-A-2·§3-A 로 들어왔다(T-69, 사용자 요청). ±1달 이동(R14)과 **년·월 피커**(연도 스테퍼 + 월 격자, 어떤 년·월로도 바로 이동 — calendar-layout.md §3)로 여러 달을 훑는 것은 이미 된다 — 여러 달을 한 화면에 나란히 늘어놓는 그리드는 P1·P2(헤더는 얇게, 기능은 접는다)에 비해 값이 작아 만들지 않기로 정했다(calendar.md §6). Phase 2 의 `calendar.md` 가 남긴 것은 **D-day** 뿐이다.
