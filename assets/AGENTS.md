# assets/ — AGENTS

## 목적

**브라우저로 나가지 않는 원본 소재**를 둔다. `public/`(그대로 서빙되는 정적 자산)과 정반대다 —
여기 있는 파일은 빌드 산출물에도, 서비스워커 프리캐시에도 들어가지 않는다. 스크립트가 읽어
`public/` 의 파일을 만들어 낼 뿐이다.

## 여기 있는 것

- `seal-icon-master-{192,512,180}.png` — 현재 배포 마스코트의 크기별 흰 배경 원본. `scripts/make-icons.mjs`가 외곽 배경만 `#F7F7F7`로 바꿔 `public/icon-*.png` 네 종을 만든다. 512 원본은 maskable에도 사용한다. 세 크기를 따로 보존해야 각각의 현재 캐릭터 픽셀을 재생성 시 그대로 유지할 수 있다.
- `seal-sheet.png` — 초기 하프물범 일러스트 자료. 현재 설치 아이콘의 재생성 원본은 아니다.

## 규칙

1. **그림을 다시 그리지 않는다.** 이 캐릭터는 고정이다 — 색·선·비율 어느 것도 코드로 재현하거나
   보정하지 않는다. 이번 배경 교체처럼 필요한 경우에도 캐릭터 픽셀은 유지한다.
   예전에 SVG 로 비슷하게 그려 넣은 적이 있는데, 그건 이 캐릭터가 아니다.
2. 원본 해상도·비트깊이를 줄이지 않는다. 현재 아이콘의 192·512·180 픽셀은 이미 확정되어 있으므로 재생성 과정에서 크기 사이의 재축소를 하지 않는다.
3. 코드 파일(`.ts`/`.tsx`/`.js`/`.mjs`) 금지 — 소재만. 처리 로직은 `scripts/`에 둔다.
4. **여기 파일은 서빙되지 않는다.** 화면에 그림이 필요하면 `public/` 로 내보내는 경로를 따로
   만들고 `scripts/check-dist.mjs` 의 계약에 넣는다. 이 디렉토리를 `public/` 처럼 쓰지 마라.
5. 제3자 그림을 넣을 때는 사용 권리를 확인한 뒤 넣는다. 배포되는 앱에 실리므로 폰트(`public/fonts/OFL.txt`)와
   같은 기준이다 — 출처·라이선스가 불분명하면 넣지 않는다.

## 검증

```bash
node scripts/make-icons.mjs   # 바뀐 배경 픽셀 수와 4종 산출물이 찍힌다
pnpm build 2>&1 | tail -3     # check-dist.mjs 가 크기·알파·프리캐시 포함을 확인
```
