Tasky

개인정보처리방침

시행일 2026년 9월 23일 · 문의 millie020524@gmail.com

Tasky 는 하루를 카테고리 색으로 꾸미며 할 일을 체크하는 작은 앱입니다. 이 문서는 Tasky 가 여러분에 대해 무엇을 저장하고, 어디에 두고, 어떻게 지울 수 있는지를 설명합니다. 법률 문서처럼 읽히지 않도록 썼지만, 여기 적힌 것이 Tasky 가 실제로 하는 일의 전부입니다.

세 줄 요약

  • 로그인하지 않으면 여러분이 적은 할 일 데이터는 여러분 브라우저 안에만 있습니다. 서버로 보내지 않습니다.
  • 구글로 로그인하면 구글 계정 식별자와 이메일 주소, 그리고 여러분의 할 일 데이터를 동기화 서버에 저장합니다. 그 이상은 받지 않습니다.
  • 광고·추적 스크립트는 없습니다. 다만 앱 화면을 열 때마다, 로그인 여부와 관계없이, 쿠키 없는 익명 방문 신호(어느 주소를 열었는지·어떤 브라우저와 기기 종류인지·페이지가 얼마나 빨리 떴는지)를 Cloudflare Web Analytics 로 보내 방문 수와 속도를 봅니다 — Tasky 가 보는 것은 나라별·기기 종류별 합계 같은 집계 통계뿐이고, 누가 왔는지, 무엇을 적었는지는 담기지 않습니다. 데이터를 누구에게도 팔거나 넘기지 않고, 언제든 내보내고, 로그아웃하고, 계정을 지울 수 있습니다.

1. 로그인하지 않고 쓸 때 — 할 일은 브라우저에만 저장됩니다

Tasky 는 로컬 우선으로 만들어졌습니다. 여러분이 적은 것은 지금 쓰고 있는 브라우저의 저장 공간 (IndexedDB)에 들어가고, 서버로 전송되지 않습니다. (앱 화면을 열 때 나가는 익명 방문 신호는 여러분이 적은 것과는 별개입니다 — 2절에 따로 적었습니다.) 저장되는 것은 다음과 같습니다.

  • 할 일 — 제목, 메모, 날짜, 완료 여부, 카테고리, 집중한 시간
  • 카테고리 — 이름, 색, 이모지
  • 루틴·D-day·다이어리 — 반복 설정, 기념일 제목과 날짜, 다이어리 본문과 기분 이모지
  • 집중 타이머 기록 — 시작·종료 시각과 길이
  • 설정 — 테마(라이트/다크)와 강조색, 마지막 백업 시각

이와 별도로 브라우저의 localStorage 에 테마 선택, 백업 확인 시각, 저장 공간 안내를 봤는지 여부 같은 화면 편의를 위한 값을 몇 개 둡니다. 개인을 알아볼 수 있는 정보는 아닙니다.

이 데이터는 브라우저의 사이트 데이터를 지우면 함께 사라집니다. 그래서 앱 안의 백업 · 복원으로 파일(tasky-backup-날짜.json)을 내보내 두는 것을 권합니다. 그 파일은 여러분 컴퓨터에만 저장되고 Tasky 는 그 파일을 보지 못합니다.

2. 앱 화면을 열 때 — 익명 방문 신호를 Cloudflare 로 보냅니다

앱 화면(로그인 화면 포함)을 열 때마다, 로그인 여부와 관계없이, Cloudflare 가 제공하는 Cloudflare Web Analytics 스크립트가 함께 실립니다. 이 스크립트는 쿠키를 만들지 않고 기기에 어떤 식별자도 남기지 않으며, 다음의 익명 페이지뷰 신호만 Cloudflare 로 보냅니다.

  • 방문한 주소 — 앱 안에서 연 페이지의 주소(경로와 쿼리 문자열, 예: 로그인이 실패했을 때의 ?auth=error). Tasky 는 주소에 이름·이메일 같은 개인 정보를 넣지 않습니다.
  • 어디서 왔는지 — 링크를 타고 왔다면 그 출발 페이지의 주소(리퍼러)
  • 브라우저 종류 — 브라우저가 스스로 밝히는 이름과 버전(user agent)
  • 기기 종류·운영체제 — 위 브라우저 정보에서 Cloudflare 가 추출합니다(예: 데스크톱/모바일, Windows/iOS)
  • 대략적인 국가 — 요청의 IP 주소로 Cloudflare 가 추정합니다. Tasky 는 나라별 합계만 보고, 도시나 더 좁은 위치는 보지 않습니다
  • 페이지 로딩 속도 — 화면이 뜨기까지 걸린 시간

이름·이메일·할 일 내용 같은 개인 식별 정보나, 방문을 이어 붙일 수 있는 지속 식별자는 여기에 담기지 않습니다. 목적은 앱이 얼마나 방문되고 얼마나 빨리 뜨는지를 보는 것 하나입니다. Tasky 가 Cloudflare 의 화면에서 보는 것은 집계된 통계(방문 수, 나라별·기기 종류별·브라우저별 합계, 속도 분포)뿐이고, 방문 한 건 한 건의 IP 주소는 받거나 저장하지 않습니다. 이 신호를 받아 처리하는 과정에서 Cloudflare 가 자체적으로 다루는 정보(예: 요청의 IP 주소)는 Cloudflare 의 개인정보 처리방침을 따릅니다.

지금은 앱 안에서 이 신호를 끄는 스위치가 없습니다. 브라우저의 추적 방지 기능이나 콘텐츠 차단기가 static.cloudflareinsights.com 을 막으면 신호는 나가지 않고, 막히든 막히지 않든 앱은 똑같이 동작합니다.

지금 읽고 있는 이 방침 페이지 자체에는 이 스크립트가 없습니다.

3. 구글로 로그인하면 — 동기화 서버에 저장됩니다

여러 기기에서 같은 할 일을 보려면 구글 계정으로 로그인합니다. 이때 Tasky 는 구글에 계정 식별자(openid)와 이메일 주소(email) 두 가지만 요청합니다. 구글이 응답에 함께 실어 보내는 다른 값(예: 이메일 확인 여부)은 저장하지 않습니다.

로그인 세션 서버가 만든 무작위 세션 번호와 만든 시각·만료 시각(브라우저에는 쿠키로) 매번 다시 로그인하지 않도록

받지 않는 것

  • 이름, 프로필 사진, 생년월일, 전화번호, 연락처, 캘린더 — 요청 범위에 없어서 구글이 주지도 않습니다.
  • 정확한 위치, 기기 식별자, 앱 안에서 무엇을 어떻게 했는지의 사용 행태 — 수집하는 코드가 없습니다. 화면을 열었다는 익명 방문 신호(브라우저 종류·기기 종류·운영체제, 그리고 Cloudflare 가 추정한 대략적인 국가의 합계)만은 예외로, 2절에 적었습니다.
  • 구글 액세스 토큰 — 로그인을 처리하는 순간에만 쓰고 저장하지 않습니다. 브라우저에도 내려가지 않습니다.
  • 결제 정보 — 결제 기능이 없습니다.

어디에, 얼마나 오래

  • 서버 데이터는 Cloudflare 의 데이터베이스(D1)에 있고, Cloudflare Workers 가 처리합니다. 브라우저와 서버 사이 통신은 HTTPS 입니다.
  • 앱 데이터와 계정 정보는 계정을 삭제할 때까지 보관합니다. 로그인한 기기의 브라우저에도 같은 데이터의 사본이 남습니다(오프라인에서도 쓰기 위해).
  • 앱에서 지운 항목은 "삭제됨" 표시로 서버에 남아 다른 기기에 삭제를 전달합니다. 계정을 삭제하면 이 표시들도 함께 지워집니다.
  • 로그인 세션은 로그아웃하면 즉시 끝나고, 로그아웃하지 않아도 쓰지 않은 채 30일이 지나면 만료됩니다. 계속 쓰는 동안은 만료가 미뤄집니다 — 만료까지 7일이 채 남지 않은 상태에서 앱을 쓰면 그 시점부터 다시 30일로 연장합니다. 만료된 세션 기록은 그 쿠키로 다음 요청이 왔을 때 서버에서 지웁니다.
  • 계정을 삭제한 뒤에는 계정 식별자와 삭제한 시각만 남깁니다 — 같은 구글 계정으로 다시 로그인했을 때 지운 계정이 되살아나지 않게 하고, 다른 기기에 "이 계정은 삭제되었습니다"를 알려 주기 위해서입니다. 이메일 주소·앱 데이터·기기 표식은 삭제 요청과 함께 한 번에 지워집니다(하나라도 실패하면 아무것도 지우지 않고 다시 시도할 수 있게 둡니다). 삭제를 요청한 기기의 세션은 그 자리에서 끝나고, 다른 기기의 세션 기록은 그 기기가 다음에 접속하는 순간 안내를 띄우면서 지워집니다 — 그 안내를 위해 그때까지만 남겨 둡니다.

쿠키

쿠키는 로그인에만 씁니다. 로그인 상태를 유지하는 세션 쿠키 하나(tasky_session, 유효기간 30일)와, 구글로 갔다 돌아오는 짧은 순간(10분)에만 쓰는 쿠키 하나 (tasky_oauth)입니다. 둘 다 스크립트가 읽을 수 없고(HttpOnly) HTTPS 로만 오가며(Secure) 다른 사이트에서 시작된 요청에는 실리지 않습니다 (SameSite=Lax). 세션 쿠키에 담기는 값은 서버가 서명한 것이라 위조한 쿠키로는 서버 조회조차 일어나지 않습니다. 추적이나 광고 목적의 쿠키는 없고, 2절의 방문 신호도 쿠키를 쓰지 않습니다.

4. 이렇게만 씁니다

  • 여러분의 데이터를 여러분 계정에 묶어 두고, 로그인한 기기들 사이에서 맞춰 주는 것.
  • 사이드바에 로그인한 이메일과 동기화 상태를 보여 주는 것.
  • 앱이 얼마나 방문되고 얼마나 빨리 뜨는지를 익명 방문 신호로 파악하는 것(2절).

그게 전부입니다. 광고를 붙이지 않고, 누가 무엇을 하는지 개인별로 사용 패턴을 분석하지 않고, 마케팅 메일을 보내지 않고, 데이터를 다른 서비스와 합치지 않습니다.

5. 제3자

  • 구글 — 로그인할 때만 관여합니다. 이때 구글이 처리하는 정보는 구글의 개인정보처리방침을 따릅니다.
  • Cloudflare — 앱을 호스팅하고 동기화 데이터베이스를 제공하며, 2절의 익명 방문 신호를 받아 방문 수와 속도로 집계해 줍니다 (Cloudflare Web Analytics). 요청과 방문 신호를 처리하는 과정에서 Cloudflare 가 자체 개인정보처리방침에 따라 다루는 정보는 Tasky 가 따로 수집하거나 들여다보지 않습니다.

이 둘 외에 데이터를 받는 곳은 없습니다. 팔지 않고, 넘기지 않고, 광고 네트워크에 보내지 않습니다. 분석 서비스는 위의 Cloudflare Web Analytics 하나뿐이고, 거기로 가는 것은 2절의 익명 방문 신호뿐입니다.

6. 가져가기와 지우기

하고 싶은 것 방법 결과
내 데이터를 파일로 갖기 앱의 백업 · 복원 → 내보내기 전체 데이터가 JSON 파일로 저장됩니다. 언제든 다시 불러올 수 있습니다.
이 기기에서만 나가기 사이드바 계정 블록 → 로그아웃 먼저 파일로 내보낸 뒤 이 브라우저의 데이터를 지웁니다. 서버와 다른 기기의 데이터는 그대로입니다.
계정과 서버 데이터를 완전히 지우기 계정 삭제 서버의 계정 정보·앱 데이터·기기 표식이 한 번에 삭제되고, 이 기기의 세션은 그 자리에서 끝납니다. 로그인돼 있던 다른 기기는 다음 접속 때 안내를 본 뒤 파일로 내보내고 자기 데이터를 지웁니다. 되돌릴 수 없습니다.
로그인 없이 쓰던 데이터 지우기 브라우저 설정 → 사이트 데이터 삭제 이 브라우저의 Tasky 데이터가 사라집니다. 서버에는 애초에 없습니다.

어느 경우든 Tasky 는 말없이 지우지 않습니다. 데이터가 사라지는 선택에는 먼저 파일로 내보낼 기회를 드립니다.
