# src/features/social/ — AGENTS

소셜은 온라인 전용이며 개인 동기화·백업 저장소와 분리한다. 공유 본문·초대 원문·작성 중 문장·멱등 키는 탭 메모리에만 둔다. 화면을 닫거나 인증·계정·권한이 바뀌면 세대를 올려 늦은 응답을 버린다.

`index.ts`는 작은 세션 경계만 정적으로 내보낸다. 상태·HTTP·화면은 첫 친구 화면 활성화 전까지 로드하지 않는다. 다른 feature를 직접 import하지 않고 셸이 인증 상태와 원본 선택을 조립한다.

## 관할: store/

현재 페이지 본문과 작성 초안·명시적 재시도 key만 탭 메모리에 보관한다. 페이지 교체와 최초 표시 전에 페이지 전체 id를 검증하고, 30초 주기·5초 deadline·35초 lease를 지킨다. 늦은 완료는 세대가 달라지면 성공·오류 모두 폐기한다.

## 관할: hooks/

렌더할 때 lease와 온라인·가시성 상태를 다시 확인한다. `snapshot.items`를 검증 없이 직접 렌더하지 않는다.

## 관할: lib/

중복 제거와 오류 코드 검증 등 피드의 작은 순수 헬퍼를 둔다. 자동 재시도나 영구 저장을 추가하지 않는다.
